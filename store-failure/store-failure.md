# Отказ хранилища

Код: `StoreFailureView.swift`, `AppContent.swift`.

Кадры этого экрана: `store-failure.png`.

## Что это

Экран, который приложение показывает вместо всего остального, если не смогло открыть базу
данных (например, файл от более новой версии приложения). Посередине заголовок
«Непредвиденная ошибка данных» и пояснение «Приложению не удалось открыть данные. Обновите
его до новой версии». Ни таб-бара, ни кнопок.

## Что делает пользователь

Внутри приложения ничего сделать нельзя: обновить приложение из App Store и запустить снова.

## Откуда открывается

Любой запуск, на котором хранилище не открылось.

## Куда ведёт

Никуда.
